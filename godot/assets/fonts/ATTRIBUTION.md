# Font Attribution

Fallback fonts for the UI's symbols (status markers ● ▶ ◆, arrows, ⚠, ⏸, ...), which Godot's built-in
Open Sans lacks. Bundled so the game does not depend on the system's fonts (wine has none with these glyphs).

- `DejaVuSans.ttf`: DejaVu Sans 2.37 (Bitstream Vera license with DejaVu changes in the public domain,
  `DejaVu-LICENSE.txt`), https://dejavu-fonts.github.io/
- `NotoSansSymbols2-Regular.ttf`: Noto Sans Symbols 2 (Debian fonts-noto-core 20201225), SIL Open Font
  License 1.1 (`OFL.txt`), https://notofonts.github.io/

Both copied unchanged from the Debian/Ubuntu font packages.
